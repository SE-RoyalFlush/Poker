# Bruno Setup (Poker-Backend)

## 1. Install Bruno
Download and install Bruno: https://www.usebruno.com/downloads

## 2. Open the Collection
1. Open the Bruno app
2. Click **Open Collection**
3. Select the folder that contains the `.bru` files:

   `tools/bruno/Poker-Backend`

## 3. Select the Environment
1. In Bruno, open the environment dropdown (often shows **No Environment**)
2. Select: **Local**

This will load the variables from `tools/bruno/Poker-Backend/environments/Local.bru`.
